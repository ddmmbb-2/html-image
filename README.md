# html-image — 圖片編輯器

單一 HTML 檔的圖片編輯器，不用安裝、不用上傳，打開就能用。
所有編輯都在瀏覽器本機完成，圖片不會離開你的電腦。

> 本機使用：下載 `index.html` 後雙擊開啟即可

## 功能

### 尺寸
- 裁切：自由、1:1、4:3、3:2、16:9、9:16
- 調整尺寸：可鎖定比例
- 旋轉：左轉 / 右轉 90°
- 翻轉：左右翻轉、上下翻轉

### 調色
- 亮度、對比、飽和度、色溫、暗角、銳利度
- 黑白、自動白平衡
- 快速色調：LOMO、暖色底片、冷色清透、高反差黑白
- 查看原圖 / 回到原圖對比

### 標註
- 文字、箭頭、框線、馬賽克、模糊
- 可調標註顏色、線條粗細、字級、文字顏色

### 圖層
- 插入多張圖片當圖層
- 拖曳移動、拖曳右下角等比例縮放
- 角度、旋轉、不透明度
- 上移 / 下移 / 刪除圖層

### 其他
- 復原 / 重做（Ctrl+Z / Ctrl+Shift+Z）
- 拖曳檔案、貼上剪貼簿圖片直接編輯
- 下載圖片：PNG / JPG / WebP，可調品質
- 另存 HTML（Ctrl+S）：存成可繼續編輯的檔案

## 怎麼用

1. 點「開啟圖片」，或把圖片拖進來、直接貼上
2. 左邊選尺寸 / 調色 / 標註，右邊管圖層
3. 完成後點「下載圖片」，或點「另存 HTML」留著下次繼續改
